| **[retrieval-reputation-layer](https://github.com/pras-ops/retrieval-reputation-layer)** | Reputation layer for any retriever: turns verified downstream outcomes into a ranking signal (Beta counters, Thompson sampling, staleness decay). Evaluated on **974 MBPP coding tasks** against a cross-encoder reranker; **[on PyPI](https://pypi.org/project/retrieval-reputation-layer/)**. | Python · sentence-transformers · FastAPI · LangChain / LlamaIndex |

| **[AnchorHeal](https://github.com/pras-ops/AnchorHeal)** | Drift early-warning and self-healing layer for Python scrapers: tracks per-selector confidence to flag scrapers that are about to break, and relocates moved elements locally without an LLM call. | Python · Selenium · Playwright · BeautifulSoup |
| **[udemy-transcript-extractor](https://github.com/pras-ops/udemy-transcript-extractor)** | Privacy-first Chrome extension that batch-extracts course transcripts in RAG-ready formats. | TypeScript · Chrome MV3 |
